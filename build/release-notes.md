**Running the downloads.** The Windows and Linux zips each hold a single self-contained executable; no .NET install is needed. On first run it extracts its native libraries to a folder in your user profile (`%TEMP%\.net` on Windows, `~/.net` on Linux) and reuses them after that. The AppImage needs FUSE to mount itself; on a system without FUSE, run it with `--appimage-extract-and-run`. Check a download against `SHA256SUMS.txt` with `sha256sum --check --ignore-missing SHA256SUMS.txt`.
